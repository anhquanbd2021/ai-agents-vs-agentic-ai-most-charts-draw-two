Ladder Lab · guide

Read the ladder
before the label.

Three controls change the same pipeline: the rung, the fence, and whether the guard is broken. This guide shows what each one proves.

Educational model. Deterministic and local — no real payments or external services.

1. Choose the rung

Pick L0, L1, L2, or L3. The lab uses the same model, tools, memory, and loop on every rung — only the decision boundary changes.

L0 — Prompt

A human chooses every step. The model can suggest, but nothing executes without you.

Proves
Richer output is not richer autonomy.
Key detail
decideRefund() always returns human.

L1 — Assisted

The model proposes a plan, and a human approves each action before it runs.

Proves
Approval throughput is a hard ceiling.
Key detail
Every step returns human until approval is granted.

L2 — Agent

The agent acts alone inside a fenced scope. Above the fence, it asks.

Proves
Autonomy is a runtime boundary, not a badge.
Key detail
The fence is fenceUsd, enforced at decision time.

L3 — Agentic

A coordinator delegates to other agents and merges their results.

Proves
Coordination is the real jump, not a rename.
Key detail
coordinateCheckout() only assigns sub-agents at L3.

2. Watch the fence

Run the same checkout batch at L2. The agent executes refunds up to the fence and hands off the rest.

Runtime guard

The check runs on every call. It is not a policy comment in the code.

Proves
Fences are executable.
Key detail
Default is 50 USD per refund.

Seeded failure

Toggle break the fence. The guard disappears and large refunds execute alone.

Proves
Runaway behavior is reproducible.
Key detail
Status changes from fenced to runaway.

3. See the coordination jump

Run the same batch at L3. The coordinator calls the payments and loyalty agents, then reports one outcome.

Typed contracts

Each sub-agent result is a typed record, not a string.

Proves
Contracts make delegation inspectable.
Key detail
toolCalls records every sub-agent invocation.

Goal success

The metric is whether the checkout goal completed, not how many agents ran.

Proves
Agent count is not autonomy.
Key detail
The summary reports handoffs and executions together.
